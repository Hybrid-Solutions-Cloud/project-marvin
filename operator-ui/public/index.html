Project Marvin

Set up Marvin once. Keep every calendar current.

Marvin is the product surface for multi-calendar sync: add Microsoft 365, Outlook, Google, and optional Apple / CalDAV calendars, link the real provider accounts, mirror meetings across them, keep mirrored events private by default, and allow family calendars to show more detail when you choose it.

What Marvin does

Every linked calendar can act as a source. Marvin applies a source prefix, preserves timezone behavior, and mirrors to every other target.

Privacy rules

Business and side-gig calendars stay private by default. Family targets can inherit subject, location, and description when you allow it.

Create the Marvin workspace account, add calendars, save provider settings, link each calendar account, validate access, then start automation.

Provider Access

Microsoft and Google need OAuth app settings that point back to Marvin. Apple / CalDAV stores an app password on each calendar record.

Microsoft and Google save client settings here first. Marvin opens the real provider sign-in only when you link a calendar. Apple / CalDAV never opens an OAuth page and is validated directly from Marvin.
