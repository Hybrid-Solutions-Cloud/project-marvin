Paranoid Keeper

Set up Paranoid Keeper once. Keep every calendar current.

Paranoid Keeper is the calendar-sync product. Project Marvin is this repository and its theme: add Microsoft 365, Outlook, Google, and optional Apple / CalDAV calendars, link the real provider accounts, mirror meetings across them, keep mirrored events private by default, and allow family calendars to show more detail when you choose it.

What Marvin does

Every linked calendar can act as a source. Marvin applies a source prefix, preserves timezone behavior, and mirrors to every other target.

Privacy rules

Business and side-gig calendars stay private by default. Family targets can inherit subject, location, and description when you allow it.

Access, Connect, Automate

Create one workspace account, add calendars, link each account, validate them, then Paranoid Keeper keeps them synchronized.
