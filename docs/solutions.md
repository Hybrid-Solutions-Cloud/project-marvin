# Product Guide

There is one supported product path: **Project Marvin**.

**Marvin Engine** is its synchronization runtime. It is not a second application to install.

## Use This Path

1. Install and open Project Marvin with `npm run marvin:install` and `npm run marvin:ui`.
2. Sign in through Microsoft Entra, or use the explicit loopback-only development sign-in locally.
3. Add and authenticate each calendar account.
4. Review privacy rules and validate access.
5. Start the runtime after at least two calendars are Ready. The hosted process auto-starts with a saved profile; only connected and validated calendars are eligible for provider work.
