# Bureaucratic Flow

This solution track is based on `MShekow/outlook-calendar-sync` and is meant for Microsoft 365-heavy scenarios.

It is the proof-of-concept track when you want to move quickly with Outlook calendars and are willing to accept the operational burdens of Power Automate.

## Commands

```powershell
./validate.ps1
./build-solution.ps1
./test.ps1
```

## What this gives you

- generated route settings
- a local solution-build staging folder
- connection templates
- import and test guidance for Power Automate

## Artifacts

Generated artifacts land under:

- `artifacts/solutions/<profile>/bureaucratic-flow/`
